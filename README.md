*Atividade — Protótipo Mobile e Organização dos Estilos com BEM*


Nessa atividade, tivemos que analisar elementos de 14 páginas web e descreve-los usando a nomenclatura BEM ensinado pelo
professor José Carmino durante as aulas. Além disso, fomos desafiados a formatar as telas de PC para telas em formato mobile,
respeitando todos os funcionamentos. Essas telas se encontram na pasta "WIREFRAMES".

- Estrutura de Pastas:


- `/CSS`: Arquivos de estilo organizados por elementos.
- `/DOCS`: Arquivo PDF contendo todas as informações e passos para a realização do projeto.
- - `/WIREFRAMES`: Imagens das 14 telas passadas para telas mobile.
- `README`: Documentação onde descrevemos o que foi feito no projeto.
